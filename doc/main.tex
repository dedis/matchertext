\section*{Data-Availability Statement}

The artifact comprises
the Lean~4 proofs of the embeddability and boundary results (\cref{app:lean,app:boundary}),
the Go library and command-line tool that converts MinML to HTML or XML,
and the source-code analyzer and corpus-collection scripts
used in the evaluation (\cref{sec:eval}),
together with the analyzer's raw results.
The corpus itself (about 1.5~TiB) is not included;
the scripts rebuild it by cloning the repositories,
whose later changes can cause small differences
from the numbers reported here.
We will submit the artifact to Artifact Evaluation.
